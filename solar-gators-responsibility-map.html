How to edit this page

You can edit everything from the browser — no text editor needed. The data section inside the file is still there as the starting point, and you can still hand-edit it if you prefer.

Editing in the browser

  1. Press ✎ Edit in the top bar.
  2. Move a topic: drag its label anywhere in the diagram. Where you drop it decides which region it counts as being in. The four Chief Engineer names can be dragged too.
  3. Change a topic: click its label. The side panel becomes a form — name, owners, description, responsibilities, notes. Changes show up immediately.
  4. Add a topic: press + Add topic. It appears in the middle of the diagram with the form open; fill it in and drag it where it belongs.
  5. Delete a topic: open it and press Delete topic at the bottom of the form.
  6. Start from a blank diagram: press Clear all to remove every topic at once. An Undo button appears for a few seconds if you change your mind.
  7. Edit a domain: click a Chief Engineer name or ellipse, then edit its tagline and mission.
  8. Edit the page title or version: click the version pill in the top-right while editing.

Saving — read this part

Your edits are kept in this browser automatically, but that copy does not travel with the file. To make a change permanent and shareable, press ↓ Save file. That downloads a fresh copy of this page with your data written into it. Replace the old file with the downloaded one — that new file is now the living document, and it opens with your changes on any computer.

The amber dot on the Save button means you have changes that are not in a downloaded file yet.

Backup, transfer, and starting over

The JSON holds only the organisational data, which is handy for moving content between versions of this page. Reset throws away every browser edit and goes back to the data written in the script.

Regions of the diagram

Dropping a label inside one of these areas puts it in that region. The form also has a Move into region dropdown that drops a topic into a free spot automatically.

Editing the file by hand instead

  • Open the file in any text editor and search for SOLAR GATORS ORGANIZATION DATA.
  • That section is the starting point. If the savedData block near the top of the file holds saved data, that wins — press Reset to file defaults to go back to the hand-written version.
  • primaryCE and everything in supportingCEs must be a CE id: aero, vd, powertrain, electrical. Use "shared" for whole-car items.
  • Every topic needs a unique id.
  • If the page renders blank you almost certainly have a missing comma or quote. Press F12 and read the red error.
