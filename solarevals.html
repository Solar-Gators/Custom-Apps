    Where versions are saved

    Versions are saved to one file in a Solar Gators GitHub repository, so the next CEs see them. Every save is also a commit, so GitHub keeps its own history too.

    Only needed to save. Anyone can look at versions without one (if the repository is public). The token stays in this browser and is never written into the page or the repository.
    How to make a token (about five minutes, once)
    1. Go to github.com/settings/personal-access-tokens/new.
    2. Name it Solar Evals; set it to expire at the end of the semester.
    3. Resource owner: Solar-Gators.
    4. Repository access: Only select repositories, then pick the repository above.
    5. Permissions → Repositories → Contents: Read and write.
    6. Generate it, copy it (starts with github_pat_) and paste it above.
